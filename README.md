# XG Prime

PLAN · LEARN · GROW. A personal command center.

v4.3: liquid-glass UI, six interface languages, goals, tasks, habits, calendar, finance records, learning progress, HVAC and migration checklists, scientific calculator, unit converter, Pomodoro, stopwatch, countdown, text utilities, secure local password generation, JSON formatter, Base64 and URL codecs, UUID generator, online reference currency conversion, offline dictionary, browser shortcuts, notes, and local backup/restore. All personal records remain in browser storage; no account or cloud sync is included. Currency rates require internet and are reference rates, not trading quotes.

Data stays in this browser's localStorage. Export (JSON) and import are included; sync is not included in this lightweight release. Market figures are demo data only, not real market data.
