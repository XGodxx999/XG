# XG Prime

PLAN · LEARN · GROW. A personal command center.

v3.1: liquid-glass UI, six interface languages (zh-CN, EN, 日本語, 한국어, ES, FR), daily goals, beginner English vocabulary (30 words, with learned tracking), manual income/expense tracking, investment records, a demo Market Overview, HVAC learning checklist, Jobs & Migration checklist, calculator, unit converter, offline English–Chinese dictionary and browser quick links, local browser storage and offline caching.

Data stays in this browser's localStorage. Export (JSON) and import are included; sync is not included in this lightweight release. Market figures are demo data only, not real market data.
