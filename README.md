# XG Prime

PLAN · LEARN · GROW. A personal command center.

**v5.1 Web** — Responsive installable PWA with six interface languages (Simplified Chinese, English, Japanese, Korean, Spanish, and French), Home / Tools / Me navigation, finance tracking, calendar and events, goals, tasks, habits, learning progress, HVAC and migration checklists, a scientific calculator, multi-category unit conversion, Pomodoro, stopwatch and countdown, text utilities, local image compression and color conversion, Markdown preview, password generation, JSON formatting, Base64 and URL codecs, UUID generation, reference currency conversion, offline vocabulary lookup, notes, and local backup/restore.

Personal records remain in this browser's local storage. User-created content is preserved as entered when the interface language changes. No account or cloud sync is included. Market figures are demo data only, not real market data. Currency rates require an internet connection and are reference rates, not live trading quotes. Image processing runs locally on the device.
